# AgroVector — визуальная и анимированная версия

Основной файл показа: `presentations/AGROVECTOR_22_SLIDES_MOTION.pptx`.

## Визуальная система

Светлый теплый фон аналитических слайдов; темные ключевые слайды 1, 5, 11, 17, 18, 22. Лесной зеленый, приглушенный лаймовый, контрастный темный текст. Прямоугольные панели, единый краевой акцент, новая векторная иллюстрация дрона над рядами поля на обложке. Иллюстрация декоративная, не карта и не спецификация оборудования.

## Движение

13 переходов Morph с резервным Fade. Именованные элементы `!!AV_progress_fill`/`!!AV_progress_rail` создают непрерывный прогресс рассказа. Поэтапное появление текстовых групп на 13 слайдах, эффект Fade 420 мс. Таблицы доказательств и календарные схемы без последовательного скрытия строк: их можно читать целиком. Переключение вручную, без автоматического таймера. При показе следующий щелчок раскрывает группу; после последней группы переходит дальше. Morph требует совместимой актуальной версии Microsoft PowerPoint; PDF и встроенное превью движения не воспроизводят.

## Сборка

После основной сборки презентации:

```bash
.venv/bin/python scripts/build_presentation_design.py
.venv/bin/python scripts/build_motion.py
```

Исходный доказательный PPTX не перезаписан. DESIGN — промежуточная статичная дизайнерская версия, MOTION — файл для выступления.

## Проверка

22 слайда, тексты, заметки, все ячейки таблиц и значения диаграмм сопоставлены с исходником без расхождений. ZIP цел, все анимационные ссылки ведут на существующие фигуры. Независимая копия открыта и сохранена Microsoft PowerPoint через AppleScript: 22 слайда, 13 Morph и 13 деревьев анимации сохранены после нативного сохранения. Это не визуальная проверка воспроизведения: интерфейсный захват не предоставил окон, живой показ эффектов не подтвержден.

Реальный PDF LibreOffice: `review/motion/AGROVECTOR_22_SLIDES_MOTION.pdf`, 22 страницы. Контактные листы всех страниц просмотрены; видимых обрезок/наложений не выявлено. Плотные таблицы и мелкие источники остаются ограничением проекционного показа. Проверочные данные: `presentations/MOTION_VALIDATION.json`.
