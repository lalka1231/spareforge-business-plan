# AgroVector — кинематографическая пересборка

Файл показа: `presentations/AGROVECTOR_CINEMATIC.pptx`. Он не заменяет бизнес-план и не изменяет финансовую базу. Прежние PPTX сохранены для сравнения. Все видео встроены в PPTX, интернет при показе не нужен.

## Сценография

1. Панорама золотого поля и неба; собственная условная 3D-модель агродрона покачивается вверх-вниз.
2. Более низкий и приближенный ракурс того же фонового поля; колосья переднего плана, движение дрона по горизонтали и иллюстративный шлейф капель.
3–22. Продолжение продуктовой среды: внесение, посевы, обследование и поле. Пять видеосцен повторно используются на 22 слайдах; это не 22 уникальные съемки. Между слайдами вертикальный Push вверх, создающий впечатление движения вниз по истории. Это монтаж, не единый непрерывный 3D-пролет камеры. Вращение винтов как отдельная проверенная анимация не заявляется.

Краткие заголовки и тезисы пересобраны по проекту. Все 22 смысловых раздела, девять блоков BMC, таблица конкурентов, Портер, Гант/сеть/RACI, финансовые диаграммы и полные исходные заметки сохранены. Полная конкурентная матрица с источниками — в notes6; на экране ее сокращенная проекция, без второй независимой таблицы. Ресурсный стресс 20 дней/месяц показан на слайде18.

## Права и честность

Источник поля: Pexels, Jess, «Aerial Footage of Wheat Field», 9130276; другие клипы и URLs — `presentations/cinematic_assets/asset_ledger.json`, исследовательская проверка — `docs/cinematic/ASSETS_RESEARCH.md`. Лицензия Pexels разрешает использование/изменение; это не CC0, запрещено выдавать сток за собственные съемки или одобрение продукта. На каждом слайде указано: «Визуализация концепции + сток Pexels. Не съемка AgroVector». Вид распыляемого вещества в стоке не установлен: удобрения и агрономический результат не объявлены доказанными по видео. Модель дрона создана процедурно, не спецификация XAG или другого производителя. Сцены сняты в разных местах; один реальный участок ими не документируется.

## Сборка

Среда: существующая `.venv`, дополнительно `imageio-ffmpeg==0.6.0`; Blender установлен по `/Applications/Blender.app/Contents/MacOS/Blender`. Исходная модель и ее PNG сохранены в cinematic_assets. Нужны исходный PPTX и data/cinematic_content.json. Медиасборщик использует /tmp-кэш исходных стоков, при отсутствии скачивает их по сохраненным публичным URL.

```bash
uv pip install --python .venv/bin/python -r requirements-cinematic.txt
# При необходимости заново отрендерить собственную модель:
'/Applications/Blender.app/Contents/MacOS/Blender' -b -t 6 --python scripts/render_cinematic_drone.py
.venv/bin/python scripts/build_cinematic_media.py
.venv/bin/python scripts/build_cinematic_presentation.py
osascript scripts/native_cinematic.applescript
# Закрыть только AGROVECTOR_CINEMATIC без сохранения перед ZIP-патчем,
# чтобы не перезаписать его устаревшим состоянием открытого документа.
osascript -e 'tell application "Microsoft PowerPoint" to close presentation "AGROVECTOR_CINEMATIC.pptx" saving no'
.venv/bin/python scripts/finalize_cinematic_media.py
# После этого повторно открыть в PowerPoint и проверить/сохранить:
# главный playFrom(0.0) должен быть With Previous, не On Click.
.venv/bin/python scripts/verify_cinematic.py
.venv/bin/python scripts/build_cinematic_preview.py
```

## Реальная проверка и ограничения

- Все пять встроенных MP4 полностью декодированы ffmpeg без ошибок; H.264/yuv420p, 1280×720, 25 fps, без аудио.
- Реальный PDF LibreOffice — 22 страницы; просмотрены контактные листы всех слайдов и увеличенный финансовый слайд. Явных крупных наложений/обрезок нет; плотные матрицы остаются ограничением проекции.
- PowerPoint действительно открывал и сохранял новый PPTX; оконный slideshow запускался, состояние Running получено через API. После исправления команды With Previous и повторного native-save PowerPoint подтвердил play-on-entry=true и loop=true на всех 22 слайдах.
- Нативный save меняет media delay на indefinite, что нормально при наличии автоматической команды playFrom в mainSeq. Проверять нужно With Previous и нулевые задержки оберток mainSeq, а не только media delay.
- Захват движущихся пикселей PowerPoint недоступен: обзор GUI не вернул окон. Поэтому визуально плавный runtime всего показа и бесшовность повторов НЕ сертифицированы; сток может заметно перезапускаться на границе петли.
- `review/cinematic/AGROVECTOR_INTRO_PREVIEW.mp4` — отдельно смонтированное 10,92-секундное превью двух первых сцен с вертикальным переходом. Не видеозапись нативного PowerPoint. Все 273 кадра декодированы; выборка кадров просмотрена.
