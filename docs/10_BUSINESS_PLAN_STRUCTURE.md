# 10. Business Plan Structure

Каркас будущей работы по структуре преподавателя.

| Раздел | Что включить в следующей версии |
|---|---|
| 1. Резюме бизнес-плана | Кратко: SpareForge, проблема недоступных пластиковых запчастей, B2B/B2C, инвестиции, break-even, GO WITH CHANGES |
| 2. Цели бизнес-плана по SMART | Например: за 6 месяцев выйти на 180 заказов/мес.; за 12 месяцев собрать 300 моделей в каталоге; заключить 10 B2B-партнерств |
| 3. Описание продукта + стратегическая канва | Продуктовые уровни Catalog Part / Print My File / Repair From Photo / Reverse Engineering / B2B Digital Shelf; сравнение с 3D-студиями |
| 4. Business Model Canvas | Использовать `docs/05_BUSINESS_MODEL.md`, уточнить после интервью |
| 5. Маркетинговый план | ЦА, каналы, емкость рынка; не смешивать AM TAM и локальный SOM |
| 6. Анализ конкурентов | Таблица из `docs/04_COMPETITORS.md`; доли рынка пока не готовы, нужны локальные данные |
| 7. Развернутый SWOT | Сильные: каталог, локальность; слабые: ручное моделирование; возможности: right to repair; угрозы: IP и копируемость |
| 8. 5 сил Портера | Высокая угроза заменителей, средние барьеры входа, высокая сила клиентов в B2C, ниже в B2B-контрактах |
| 9. ОПФ | Для РФ вероятно ИП на старте или ООО для B2B; требуется юридическая проработка |
| 10. Стейкхолдеры Власть/Интерес | Клиенты, мастерские, поставщики, арендодатель, регуляторы, правообладатели, курьеры |
| 11. Производственный план | Технология FDM, конфигурации оборудования, мощность, контроль качества |
| 12. Организационный план | Основатель/CAD, оператор, продажи/админ, внешняя бухгалтерия |
| 13. Иерархическая структура работ | Исследование, закупка, сайт, каталог, партнерства, запуск производства |
| 14. Диаграмма Ганта | 12-16 недель: исследование, закупка, настройка, тестовые детали, продажи, запуск |
| 15. Сетевой график | Зависимости: помещение → оборудование → материалы → тесты → каталог → продажи |
| 16. Матрица ответственности | RACI: основатель, оператор, CAD, маркетинг, бухгалтер, партнерские мастерские |
| 17. Финансовая модель | Использовать `docs/08_FINANCIAL_MVP.md`, затем расширить помесячно на 3 года |
| 18. NPV | Требуются ставка дисконтирования, налоговый режим, сценарии выручки |
| 19. Потребность в инвестиционных ресурсах | Базово 1,12 млн руб. CAPEX + оборотный резерв |
| 20. Структура источников инвестиций | Собственные средства, грант, заем, партнерская предоплата сервисных центров |
| 21. Основные технико-экономические показатели | Средний чек, COGS, маржа, мощность, break-even, окупаемость |
| 22. Анализ рисков | IP, безопасность, брак, спрос, конкуренция, поставки материалов, пожарная/вентиляция |

## Что уже можно переносить в бизнес-план

- описание продукта;
- Business Model Canvas;
- первичная конкурентная таблица;
- производственная модель;
- unit-экономика;
- CAPEX/OPEX и break-even;
- зарубежные кейсы и источники.

## Что пока нельзя считать финальным

- доли рынка;
- локальная емкость рынка;
- окончательный налоговый режим;
- NPV;
- юридическая позиция по копированию деталей;
- точная локальная смета оборудования и аренды.
