# Правки по замечаниям преподавателя

Актуальный проект: AgroVector agrodrones / АгроВектор. Проверка 06.10.2026.

1. Раздел 3: конкретные компании вместо обобщенных альтернатив. Максимальные оценки проекта удалены. Числовая канва оценивает публичную доказательность предложения; неизвестные характеристики отмечены Н/д, план проекта отделен от фактов конкурентов.
2. Раздел 5: TAM ограничен выбранным сегментом, SAM — кластером; входные числа остаются сценарными. Формулы пересчитаны. Добавлены отдельные доли по внесению (6,67%) и мониторингу (13,33%), проверка мощности и чувствительность пригодности. Несовпадение микса SOM раскрыто: сопоставимый микс дает 8,3 млн руб., базовая финансовая цель — 8,8 млн руб.
3. Раздел 6: таблица долей по именованным конкурентам и единая методика. Публичных сопоставимых процентов не найдено. Публикация Агропрофи «50 тыс.+ га» не раскрывает год и территорию, поэтому не превращена в долю рынка.

Повторно проверенные первичные страницы: https://xag-ap.ru/ ; https://agrdron.ru/ ; https://germes-technology.ru/ . BeeUAV повторно недоступен; прежние сведения не объявлены свежими.

Правка относится к текстовому документу. Прежняя презентация содержит старую канву и требует отдельного обновления перед новым показом.
