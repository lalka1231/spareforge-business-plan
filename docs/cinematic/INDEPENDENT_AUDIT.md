## Замечания и границы подтверждения

### 1. Фактический media XML не соответствует буквальному delay=0

На КАЖДОМ слайде 1–22 фактический путь
`p:timing//p:cMediaNode/p:cTn/p:stCondLst/p:cond/@delay`
равен `indefinite`, не `0`. У media `p:cTn` стоит `repeatCount="indefinite"`, `fill="hold"`, `display="0"`: бесконечный повтор структурно подтвержден. Указанный `display="0"` не следует путать с нулевой задержкой старта.

PowerPoint также записал основную последовательность с командой `playFrom(0.0)` и локальными `delay="0"`, но у внешнего узла `cTn id="3"` — `delay="indefinite"`, эффект `nodeType="clickEffect"`. Поэтому наличие строки `playFrom(0.0)` само по себе не доказывает автоматический запуск при входе. Это отличается от исходного генератора, который ставит media delay=0 напрямую.

По предоставленному контексту нативный PowerPoint уже открыл и сохранил файл, `animationplaysettings` показал autoplay/loop=true, запуск slideshow и window/run state проверены. Эти сведения приняты как ранее полученные, не повторялись данным аудитом. Не следует объявлять runtime отказ только по нормализованному XML, но и строгий XML-критерий delay=0 выдавать за выполненный нельзя. Для окончательной приемки движения необходима наблюдаемая смена кадров на слайдах.

### 2. Валидационный JSON устарел относительно файла

`presentations/CINEMATIC_VALIDATION.json` содержит SHA-256 `5e58fadb24565963db7a17ecc695437f7eca3f4d40f795710e6e46fc8d33e367`, не совпадающий с проверенным PPTX, и `autoplay_loop_xml: true`. Текущий XML подтверждает loop, но не прежний media delay=0. Поле `native_slideshow_playback: "not yet verified"` также не отражает предоставленные сведения о более поздней нативной проверке. JSON нельзя использовать как актуальный сертификат финального артефакта без обновления. В рамках read-only аудита он не изменялся.

### 3. Звук

В текущем XML на всех 22 слайдах `cMediaNode/@vol="80000"`, хотя генератор задавал `0`. Это отдельное расхождение после сохранения, не доказательство слышимого звука: аудиодорожки и фактическая громкость здесь не тестировались.
