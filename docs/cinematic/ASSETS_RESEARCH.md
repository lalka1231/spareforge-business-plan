# AgroVector — кинематографические видеоматериалы

## Результат

Найдены три основных горизонтальных клипа под монтаж «агродрон → поле сверху → колосья». Все три **полностью скачаны без аккаунта** в /tmp; сервер вернул HTTP 200, локальные файлы распознаны утилитой `file` как MP4. Проект AgroVector не изменялся. Дополнительно проверены три запасных файла запросом Range: HTTP 206, Content-Type video/mp4 и реальные байты контейнера.

## Как воспроизвести загрузку

Публичный download-адрес `https://www.pexels.com/download/video/ID/` с обычным User-Agent перенаправляет на приведенный CDN-файл. Некоторые HTML-страницы Pexels и запросы urllib без User-Agent возвращали 403. Прямые файлы из основного набора скачаны успешно; браузерный инструмент недоступен из-за неподдерживаемого браузера по умолчанию. Обход авторизации не применялся.

Пример:

```sh
curl -L --fail -A 'Mozilla/5.0' 'https://videos.pexels.com/video-files/37280502/15793273_3840_2160_25fps.mp4' -o /tmp/agrovector-drone.mp4
```

Оригиналы 4K тяжелые; перед внедрением в PPTX разумно подготовить короткие 1080p/H.264 фрагменты и сохранить атрибуцию в примечаниях. Перекодирование и изменение PPTX в рамках этого задания не выполнялись. Специально лицензированная анимация агродрона не найдена; вместо нее имеется реальный стоковый видеоклип. Официальные рекламные ролики производителей не предлагаются без ясной лицензии.
