## 2. Независимый метод

Выполнен отдельный Python-пересчет стандартной библиотекой `decimal`, точность 40 знаков. Генератор и `verify.py` не импортировались и не использовались как калькулятор. Исходные входы прочитаны из `data/assumptions.csv`, затем независимо собраны объемы, тарифы, переменные, фиксированные расходы, налоги, CAPEX и потоки каждого года. Для всех пяти лет максимальное абсолютное отклонение семи полей (выручка, переменные, фиксированные, EBITDA, УСН, замены, FCF) от `financial_model_5y.csv` равно **0,0 руб.** Двенадцать месячных остатков пересчитаны отдельно; максимальное отклонение равно **0,00 руб.** Проверены все шесть сценариев собственной реализацией; совпадение с `sensitivity.csv` в пределах округления.

Формулы: `R = Qt × 1300 × 1,04^i + Qm × 250 × 1,04^i`; `V = (Qt × 400 + Qm × 60) × 1,05^i`; `F = 4200000 × 1,05^i`; `EBITDA = R − V − F`; `УСН = 0,06R`; `FCF = EBITDA − УСН − CAPEXзамен + возвратрезерва`; `NPV = −9500000 + Σ FCFt / 1,24^t`. Здесь i=0 для 2027. Цены и затраты индексируются, замены заданы номинально без повторной индексации.

Воспроизводимый минимальный независимый расчет (запускается через `python3 -c` или Python, файлов не пишет):

```python
from decimal import Decimal as D
qt = [6000, 9000, 11000, 12000, 13000]
qm = [4000, 6000, 8000, 9000, 10000]
cap = [0, 300000, 600000, 900000, 600000]
flows = [D(-9500000)]
for i in range(5):
    revenue = (D(qt[i])*1300 + D(qm[i])*250)*D('1.04')**i
    variable = (D(qt[i])*400 + D(qm[i])*60)*D('1.05')**i
    fixed = D(4200000)*D('1.05')**i
    cf = revenue*D('.94')-variable-fixed-cap[i]
    flows.append(cf+(D(2000000) if i == 4 else D(0)))
print(flows)
print(sum(cf/D('1.24')**t for t, cf in enumerate(flows)))
```
