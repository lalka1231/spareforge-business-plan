# AgroVector agrodrones — АгроВектор

**Сервис применения сельскохозяйственных дронов для мониторинга посевов и точечного внесения удобрений, средств защиты растений и биопрепаратов.**

Бизнес-план ранней стадии для агропартнера и долевого инвестора. Актуальная редакция: **06.10.2026**. Расчетный горизонт: **2027–2031**. Исходные финансовые допущения датированы 05.09.2026; они не объявляются подтвержденными рыночными данными.

## С чего начать

Основной документ для проверки — [полный бизнес-план Word](documents/AGROVECTOR_FULL_BUSINESS_PLAN.docx). Для выступления — [презентация на 22 слайда](presentations/AGROVECTOR_22_SLIDES.pptx). Для чтения прямо в GitHub — [текст бизнес-плана](docs/FINAL_BUSINESS_PLAN.md).

В актуальной редакции SMART-цели имеют измеримые результаты, даты и ответственных; описание продукта и качественная стратегическая канва сопоставлены с конкретными конкурентами без произвольных баллов; бизнес-модель раскрыта по девяти блокам. Word и презентация согласованы. [Правила единой редакции и проверка](docs/UNIFIED_STANDARD_2026_10_06.md).

## Предложение клиенту

[ДОПУЩЕНИЕ] Клиент покупает услугу, а не дрон: обследование поля, выявление проблемных зон, согласованное точечное внесение, выпуск энтомофагов, работу на сложных участках и отчет. Основные покупатели — малые и средние сельхозпредприятия и КФХ; агрохолдинги — вторичный сегмент. Полноценное орошение водой и продажа техники исключены.

[ДОПУЩЕНИЕ] Запуск — одна мобильная бригада в Татарстане, до 150 км от базы, только после подтверждения юридической доступности участков. Парк: основной и резервный аппараты внесения плюс мониторинговый БВС. Гражданская переподготовка людей с опытом БПЛА после СВО строится на добровольности, наставничестве и единых требованиях к безопасности.

## Экономика базового сценария

[РАСЧЕТ] На основе проектных допущений, не подтвержденных договоров:

| Показатель | Значение |
|---|---:|
| Стартовая потребность | 9,50 млн руб. |
| CAPEX / запуск / ликвидность | 7,00 / 0,50 / 2,00 млн руб. |
| Внесение / мониторинг, 2027 | 6000 га-проходов / 4000 га-обследований |
| Выручка / EBITDA, 2027 | 8,80 / 1,96 млн руб. |
| NPV, 5 лет, ставка 24% | +3 946 443 руб. |
| Простая / дисконтированная окупаемость | 2,68 / 3,88 года |

[ДОПУЩЕНИЕ] Тарифы 2027: внесение 1300 руб./га-проход, мониторинг 250 руб./га-обследование, без НДС и препаратов клиента. НДС добавляется при возникновении обязанности. Долг, гранты и продажа оборудования в конце горизонта не финансируют результат; возврат резерва 2 млн руб. в конце пятого года выделен отдельно.

[РАСЧЕТ] При объеме −25% NPV составляет **−2,64 млн руб.**; при цене внесения 900 руб./га в 2027 с последующей индексацией — **−6,61 млн руб.** Базовая цена требует подтверждения платным пилотом.

**Инвестиционное решение: условное поэтапное финансирование.** Нет подтвержденных контрактов, разрешений, коммерческих предложений на парк или внесенного капитала. TAM/SAM — явно обозначенный сценарий спроса, а не установленный размер российского рынка. Неизвестные доли конкурентов не заменены выдуманными процентами.

## Рынок и закупочные ограничения

[РАСЧЕТ] Сценарный TAM — **1,245 млрд руб./год**, SAM — **124,5 млн руб./год**, SOM первого сезона — **8,8 млн руб.** SOM/SAM: **7,07% выручки**, **6,67% га-проходов внесения**, **13,33% га-обследований**. Это разные знаменатели, не доля уже работающей компании. Предполагаемые 2 000 / 200 хозяйств требуют адресного реестра; состав услуг SOM отличается от SAM.

[ДОПУЩЕНИЕ] Базовые **4 млн руб. на два аппарата внесения** пока являются лимитом без подтвержденного КП. [Агропрофи](https://xag-ap.ru/) на 06.10.2026 публикует XAG P100 Pro за 2,99 млн руб. за комплект. Два комплекта дают 5,98 млн руб.; при прочих равных финансирование увеличивается до **11,48 млн руб.**, условная NPV снижается до **1,966 млн руб.** Это отдельный закупочный стресс, не новая базовая модель. До закупки проверяются комплектация, налоги, отсутствие повторного счета обучения и фактическая выработка.
